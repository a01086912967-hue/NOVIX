결제 순서

  1. 위 버튼으로 NOVIX 공식 디스코드 서버에 들어가요.
  2. 결제 · 문의 채널에서 티켓 열기를 눌러요.
  3. 티켓에 원하는 플랜과 적용할 서버 ID를 적어요. (아래에서 복사할 수 있어요)
  4. 관리자가 티켓 안에서 결제 방법을 안내해드려요.
  5. 확인되면 바로 서버에 적용되고, /프리미엄 상태로 확인할 수 있어요.
