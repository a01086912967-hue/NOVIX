# NOVIX 봇 + 웹 대시보드

서버 운영을 봇 하나로. 프로필 상태에 **"N명 보호 중이에요 !"** 표시 (10분마다 갱신).
봇과 웹사이트가 **한 Railway 서비스**에서 같이 돌아가요.

## 처음부터 설치

### 1. 디스코드 봇
1. https://discord.com/developers/applications → **New Application** → `NOVIX`
2. **General Information** → 아이콘에 `novix-icon.png`
3. **Bot** 탭
   - **Reset Token** → 토큰 복사
   - **Privileged Gateway Intents** 켜기: ✅ SERVER MEMBERS ✅ MESSAGE CONTENT
4. **OAuth2** 탭
   - **Client ID**, **Client Secret** 복사 (웹 로그인용)
   - **Redirects**에 `https://내도메인/callback` 추가 (도메인 전엔 `https://xxx.up.railway.app/callback`)

### 2. Railway
1. **New Project → Deploy from GitHub repo**
2. **+ New → Database → PostgreSQL**
3. 봇 서비스 → **Settings → Networking → Generate Domain** (웹 주소 생성)

### 3. Railway Variables
| 이름 | 값 |
|---|---|
| `DISCORD_TOKEN` | 봇 토큰 |
| `DATABASE_URL` | Add Reference → Postgres → DATABASE_URL |
| `BOT_OWNER_ID` | 내 디스코드 ID (설정 → 고급 → 개발자 모드 → 내 프로필 우클릭 → ID 복사) |

### 3-1. 웹 인증 (선택이지만 추천)
| 이름 | 값 |
|---|---|
| `PROXYCHECK_KEY` | https://proxycheck.io 무료 가입 → Dashboard의 API Key (VPN 검사, 하루 1,000회 무료) |
| `TURNSTILE_SITE_KEY` / `TURNSTILE_SECRET` | Cloudflare 대시보드 → **Turnstile → Add site** → 도메인 입력 → 나오는 두 키 (사람 확인 체크박스) |
| `BEHIND_CLOUDFLARE` | 4번에서 Cloudflare 프록시를 켠 뒤 `true` |

서버에서: `/인증 설정 역할:@인증됨` → 인증 채널에 버튼이 생겨요.
@everyone은 채널을 못 보게, `@인증됨`만 보이게 권한을 바꾸면 인증해야만 서버를 쓸 수 있어요.

**알아둘 점**
- IP는 원본을 저장하지 않고 되돌릴 수 없는 암호값(해시)으로만 비교해요. 관리자도 IP를 볼 수 없어요.
- **같은 IP = 부계정 의심**이라서 가족·학교·같은 와이파이, 그리고 휴대폰 데이터(통신사가 여러 사람에게 같은 IP를 줄 때가 있어요)는 진짜 다른 사람이어도 막힐 수 있어요. 막히면 로그 채널에 "같은 IP로 인증한 계정"이 같이 뜨니까, 진짜 다른 사람이면 `/역할 지급`으로 직접 넣어주거나 `/인증 초기화`를 쓰세요. 너무 자주 막히면 `/인증 설정 부계정차단:False`.
- 서버에 IP를 검사한다는 안내(개인정보 처리 안내)를 공지해두는 게 좋아요. 인증 페이지에도 안내 문구가 나와요.

### 3-2. 결제 (지금 방식: 공식 디스코드 서버에서 수동)
사이트의 구매 버튼 → `/checkout` 결제 안내 페이지 → **공식 디스코드 서버로 이동** → 티켓으로 결제 → 관리자가 `/프리미엄 지급`.
- Railway 변수 `SUPPORT_SERVER_URL` = 공식 서버 초대 링크 (`https://discord.gg/xxxx`, **만료 없음**으로 만들기)
- 공식 서버에 `#결제-문의` 채널을 만들고 `/티켓 패널 관리역할:@관리자`
- 결제 확인 후: `/프리미엄 지급 서버id:(손님 서버 ID) 플랜:프리미엄 일수:30`
- 결제 페이지에서 손님이 자기 **서버 ID를 복사**할 수 있어요.

> 아래 "자동 승인" 기능은 코드에 남아 있지만 지금 결제 페이지에서는 쓰지 않아요. 나중에 자동으로 바꾸고 싶으면 알려주세요.

#### (참고) 계좌이체 자동 승인

플랜: 무료 / 프리미엄 3,500원 / 프리미엄+ 9,900원 (30일, `src/db.js`의 `PLANS`에서 변경)

**흐름**: 사이트 `/checkout` → 로그인 → 플랜·서버·이름 → "본인이 직접 입금" 체크 → 주문 만들기 →
**정가**(3,500원) + **주문 코드가 붙은 입금자명**(예: `N482홍길동`) 안내 → 은행 앱 "받는 분 통장 표시"에 그대로 입력해서 입금 →
입금 알림이 `/api/deposit`으로 들어오면 **코드 + 금액**으로 주문을 찾아 → 자동으로 프리미엄 지급 + 구매자 DM + 나에게 알림.

**왜 코드를 붙이나요? (3자 사기 방지)**
3자 사기: 사기꾼이 NOVIX에서 주문을 만들고, 중고거래 등으로 속인 **다른 사람**에게 "이 계좌로 입금해"라고 시켜요. 그러면 사기꾼은 프리미엄을 받고, 피해자는 NOVIX 계좌를 사기 계좌로 신고해서 **내 계좌가 지급정지**될 수 있어요.
- 결제 페이지에 경고 + "본인이 직접 입금" 체크를 해야만 주문이 돼요.
- 입금자명에 **코드가 없으면 자동 승인을 안 하고** "3자 사기일 수 있어요" 알림이 와요.
- 이상한 입금(코드 없음, 금액 다름, 입금자 실명이 구매자와 전혀 다름)은 **승인하지 말고 입금한 분께 돌려주세요.**
- 코드 앞글자는 `DEPOSIT_PREFIX`(기본 `N`)로 바꿀 수 있어요.

**Railway 변수**
| 이름 | 값 |
|---|---|
| `BANK_NAME` / `BANK_ACCOUNT` / `BANK_HOLDER` | 은행명 / 계좌번호 / 예금주 (결제 페이지에 표시돼요) |
| `DEPOSIT_SECRET` | 영어·숫자 32자 이상 아무렇게나 (입금 알림 주소의 비밀번호) |
| `PAYMENT_LOG_CHANNEL_ID` | (선택) 결제 알림 받을 채널 ID, 비우면 나에게 DM |

**입금 알림 연결 (둘 중 하나)**
- **A. 입금확인 서비스** (폰 필요 없음, 보통 유료): 뱅크다 같은 서비스에 결제용 계좌를 등록하고, 웹훅(알림 주소)을
  `https://novixbot.shop/api/deposit?key=DEPOSIT_SECRET값` 으로 설정. `{"name": "N482홍길동", "amount": 3500}` 같은 형식이면 바로 돼요.
- **B. 안드로이드 폰 + "SMS to URL Forwarder"** (무료, 폰은 계속 켜져 있어야 함)
  1. 은행에 **입출금 문자(SMS) 알림** 신청 (은행 앱 푸시 말고 **문자**여야 해요)
  2. F-Droid 또는 GitHub에서 **SMS to URL Forwarder** 설치 (구글 플레이에는 없어요)
  3. 규칙 추가: 보낸 사람 `*` (또는 은행 번호), 텍스트 필터 `입금`,
     Webhook URL `https://novixbot.shop/api/deposit?key=DEPOSIT_SECRET값`,
     JSON payload `{"from": "%from%", "text": "%text%"}`
  4. 문자가 RCS(채팅)로 오면 Google 메시지에서 RCS 채팅을 꺼주세요 (문자만 전달돼요)
  5. 폰 배터리 최적화에서 이 앱은 **제외**해두면 꺼지지 않아요

**잘 되는지 확인**: 사이트에서 주문을 하나 만든 뒤 디스코드에서
`/결제 테스트 문장:입금 3,500원 N482홍길동` (내 주문의 금액·입금자명으로) → "자동 승인됐어요"가 나오면 성공.

**자동으로 안 맞을 때**: 금액이나 이름이 다르면 나에게 "확인 필요한 입금" 알림이 와요.
`/결제 목록` → `/결제 승인 주문번호:12` 로 직접 승인. `/결제 입금기록` 으로 들어온 알림 확인.

> 정기적으로 돈을 받고 판매하면 사업자등록·통신판매업 신고가 필요할 수 있어요. 환불 규정(플랜 페이지 맨 아래)도 내 규칙에 맞게 고쳐주세요.

### 3-3. 노래방 (프리미엄)
봇이 유튜브 소리를 직접 틀지 않아요 (유튜브 약관 위반). **유튜브 공식 검색**으로 노래방 영상을 찾고, 디스코드 공식 **"같이 보기(Watch Together)"**로 음성 채널에서 다 같이 봐요. TJ·금영 노래방 영상은 **화면에 가사**가 나와요.

1. **유튜브 키 받기**: https://console.cloud.google.com → 프로젝트 만들기 → "API 및 서비스" → **YouTube Data API v3** 사용 설정 → 사용자 인증 정보 → **API 키 만들기** → Railway `YOUTUBE_API_KEY`
   - 무료로 하루 검색 약 100번 (곡 신청 1번 = 검색 1번)
2. 서버에서 `/노래방 지정 음성채널:#노래방 패널채널:#노래방-신청` → 패널이 올라가요
3. NOVIX 권한: 음성 채널 **초대 만들기**, 무대 모드 쓰면 **멤버 음소거**

**패널 버튼**: 🎤 곡 신청(제목 입력 → 검색 결과에서 고르기) · ⏭️ 시작/다음 곡(부른 사람·관리자) · 📋 대기열 · 🙅 내 신청 취소 · ⏹️ 종료(관리자)
노래 중: 📺 **같이 보기** 링크 · ▶️ 유튜브 링크 · ⭐1~5 관객 점수(프리미엄+)
곡이 끝나면 🎙️ **NOVIX 점수** + ⭐ **관객 평균 점수** 발표 → `/노래방 랭킹`
- **NOVIX 점수**: 노래가 시작되면 봇이 음성 채널에 들어가서 **부르는 사람 목소리만** 실시간으로 듣고 계산해요. 녹음·저장은 안 해요.
  - 부른 시간(얼마나 꾸준히 불렀나) · 음량 안정 · 음정 안정(음이 갑자기 튀지 않나) → 50~100점
  - 원곡 음정과 비교하는 건 아니에요 (원곡 멜로디 데이터가 없어서)
  - NOVIX 권한: 음성 채널 **연결**. 못 들어가면 그 곡은 관객 점수만 나와요
- **MR로 부르기**: `/노래방 mr 파일:(mp3 등) 제목:` → 내 차례에 NOVIX가 음성 채널에서 **직접 틀어줘요**. MR이 끝나면 자동으로 다음 곡. (정식으로 구한 MR만 올려주세요)
  - 유튜브 영상 소리를 봇이 트는 건 유튜브 약관 위반이라 안 넣었어요. 영상 곡은 지금처럼 "같이 보기"로 불러요.
- 신청·다음 곡·종료·취소 같은 알림은 **나만 보이게**, 내 차례는 **DM**으로 와요. 점수 발표만 채널에 올라가요.
무대 모드(프리미엄+): 부르는 사람 빼고 자동 음소거, 끝나면 자동 해제. 문제 생기면 `/노래방 초기화`.

> 봇이 재시작되면 대기열은 비워져요 (점수 기록은 남아요).
> 내 서버에서 써보려면 `/프리미엄 지급 플랜:프리미엄+ 일수:3650` 으로 직접 넣으면 돼요.

### 4. 개인 도메인(.com) + 디도스·봇 방지 (Cloudflare 무료)
1. 도메인 구매 (가비아, Cloudflare, Namecheap 등)
2. https://dash.cloudflare.com 에 도메인 추가 → 안내하는 **네임서버 2개**를 도메인 구매처에 입력
3. Railway → 봇 서비스 → **Settings → Networking → Custom Domain**에 `내도메인.com` 입력 → 나오는 CNAME 값을 Cloudflare **DNS**에 추가 (**주황 구름 = 프록시 켜기**)
4. Cloudflare 설정
   - **SSL/TLS → Full** (Flexible이면 무한 새로고침 생김)
   - **Security → Bots → Bot Fight Mode 켜기** (봇 방지)
   - **Security → Settings → Security Level: Medium** 이상, 공격받을 땐 **Under Attack Mode**
   - 디도스 방어는 프록시만 켜도 자동 적용
5. Railway `PUBLIC_URL`을 `https://내도메인.com`으로, 디스코드 OAuth2 Redirect도 `https://내도메인.com/callback`으로 변경

사이트 자체에도 요청 횟수 제한(IP당 1분 120회), 다른 사이트에서 보낸 요청 차단, 보안 헤더가 들어 있어요.

### 5. 서버에서 처음 설정
```
/설정 로그채널 채널:#로그
/설정 환영채널 채널:#환영
/설정 자동모더 사용:True
/레벨 설정 사용:True
```
⚠️ 서버 설정 → 역할에서 **NOVIX 역할을 맨 위쪽으로** 올려야 밴/킥/역할 지급이 돼요.

## 웹사이트 주소
| 주소 | 내용 |
|---|---|
| `/` | 메인 페이지 |
| `/plans` | 플랜 (결제 기능은 다음 단계) |
| `/login` | 디스코드로 로그인 |
| `/app` | 대시보드: 개요 · 환영·역할·로그 · 자동모더 · 경고 처벌 · 레벨 · 인증(인증 메시지 보내기) · 자동응답 · 임베드/자동 메시지 |
| `/verify` | 웹 인증 페이지 (디스코드 인증 버튼으로만 들어올 수 있음) |
| `/admin` | **봇 주인 전용** 관리자 페이지: 개요(통계·명령어 그래프), 서버 목록·프리미엄 지급/회수·나가기, 로그인 기록, 인증 기록, 주문 |
| `/privacy` | 개인정보 처리 안내 (맨 아래 `[연락처]`, `[날짜]`를 채워주세요) |
| `/invite` | 봇 초대 링크 |

대시보드는 **서버 관리 권한**이 있는 사람만 쓸 수 있고, 요청할 때마다 봇이 직접 권한을 다시 확인해요.
관리자 페이지(`/admin`)는 `BOT_OWNER_ID`에 있는 사람만 열려요. 대시보드 오른쪽 위에 **관리자** 링크가 보여요.
로그인 기록의 IP는 기본으로 앞부분만 저장해요(예: `218.158.*.*`, 30일 뒤 자동 삭제). 전체 IP가 꼭 필요하면 `LOG_FULL_IP=true` (개인정보 처리 안내도 같이 고쳐주세요).
