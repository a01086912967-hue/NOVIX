    자동모더

    관리자와 메시지 관리 권한이 있는 사람은 검사에서 빠져요.

    금지어

    경고 처벌

    /경고가 이 횟수만큼 쌓이면 자동으로 처벌해요. 0이면 꺼져요.

    레벨

    채팅하면 XP가 쌓여요 (1분에 한 번). 레벨이 오르면 알림과 보상 역할을 줘요.

    레벨 보상 역할

    인증

    인증 버튼을 누르면 사이트에서 검사 후 역할을 줘요. 막힌 기록은 로그 채널에 남아요.

    ⚠️ 사이트 주소(PUBLIC_URL)가 설정되지 않아 웹 인증을 쓸 수 없어요.

    인증 메시지 보내기

    설정을 저장한 다음, 인증 버튼이 달린 메시지를 채널에 올려요.

    자동응답

    키워드가 들어간 메시지에 봇이 자동으로 대답해요. 대답에 {user} {username} {server}를 쓸 수 있어요.
